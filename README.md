# BeautyFolio Launch

Build the BeautyFolio Homepage

Project Overview

Build the homepage for BeautyFolio, India's Digital Growth Platform for Beauty Professionals.

BeautyFolio is NOT

 A marketplace

 A listing directory

 A social media agency

BeautyFolio helps beauty professionals build their own digital identity through SEO-optimized portfolios, helping them become discoverable on Google, AI Search, and Local Search to generate direct enquiries without relying solely on Instagram or paying marketplace commissions.

Our positioning is:

"We don't help beauticians become influencers. We help them become customers' first choice on Google."

The homepage should instantly communicate trust, professionalism, authority, and business growth.

Objective

Design a premium SaaS homepage that converts beauty professionals into free users.

Primary CTAs

 Create Free Portfolio

 Book Demo

Secondary Goals

 Explain the platform

 Build trust

 Demonstrate the product

 Increase conversions

 Encourage users to explore Pricing and Portfolio Examples
