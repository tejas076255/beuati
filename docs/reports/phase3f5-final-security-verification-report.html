6. Same-Profile Test Result

Tests A, B, and F all succeeded exactly as expected: same-profile Gallery link, same-profile Before/After link, and a service rename that left the relationship (service_id) completely unchanged while the join query correctly picked up the new name.

7. SET NULL Delete Behavior

Test G confirmed: deleting a linked service automatically set the media's service_id to NULL; the media row itself was untouched. Verified inside a controlled, rolled-back transaction so the real "Nail Art" service was never actually lost — Postgres fires FK actions during the transaction regardless of whether it's later committed or rolled back, so this is a faithful test of the real code path with zero permanent risk.
