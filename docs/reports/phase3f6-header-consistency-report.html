The Fix

Added the exact same public portfolio header/nav pattern from /portfolio/{slug} to the service detail page — reused, not rebuilt. Professional name (left, links to the portfolio's #top), desktop nav (About / Work / Transformations / Services / Packages / Reviews / Videos), Check availability CTA (right), and the same mobile hamburger menu with the same 9-item list — identical structure/classes to the main page's header.

Every nav item is a cross-page link back to /portfolio/{slug} with the matching hash (#about, #gallery, #transformations, #services, #packages, #reviews, #videos, #faq, #contact) — the same anchors the main page's header already uses. Both the header CTA and the mobile-menu CTA carry ?service={name} + #availability, preserving the service-aware availability flow from earlier in Phase 3F.6.
