1. Existing Semantic Architecture Discovered

JSON-LD was a flat array of independent objects with no shared @id — founder, creator, and provider each re-declared a duplicate inline Person object instead of referencing one entity. sameAs was never populated despite real Instagram/Facebook/YouTube/website URL fields already existing on the Profile page. areaServed vs. primary location were already correctly distinguished — no fix needed there. Homepage canonical/og:url were present but relative, not absolute.

2. Primary Entity Decision

Hybrid model: Person + LocalBusiness, connected as two nodes — not collapsed into one type. A profile always carries individual data (bio, experience, portrait) and business-like data (address, hours, service catalog); dropping either would lose real information. Kept the existing ["BeautySalon","LocalBusiness"] type as-is — not swapped for a different type "because it sounds better."
