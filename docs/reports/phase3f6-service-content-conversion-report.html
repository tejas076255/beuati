1–2. Audit & Conversion Weaknesses Found

Present already: breadcrumb, H1, provider line + verified badge, city, top CTAs, description, pricing, service areas, relevant gallery, before/after, aggregate trust stat, FAQ link-out, back-link block. Missing/weak: appointment-type/travel info despite real data existing; no "Other services" internal links; no bottom-of-page CTA; no mobile sticky CTA on this route; reviews heading conflated bio wording with trust data; hero showed no rating/experience/price summary.

Biggest conversion weakness found: the "Check availability" CTA left the service page and dropped into the main portfolio's generic form with zero service context carried over — the customer had to re-select the exact service they'd just come from.

9. Service Context → Lead-Flow Finding (Real Gap, Fixed)

The form already sent _service_requested (free text) but never _service_id, even though the RPC and FK already supported it. Now resolves the selected service to its real id and passes both — giving leads a genuine relational link instead of only a text label. Zero schema changes required.
